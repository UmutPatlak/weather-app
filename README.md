# 🌤️ Modern Weather App

A beautiful, fully functional Weather Application built with Vanilla JavaScript, HTML, and Tailwind CSS. The app features a stunning **Glassmorphism** UI and uses **Clean Architecture** principles.

## ✨ Features
- 🔍 Real-time weather data fetching via Open-Meteo API
- 🎨 Premium Glassmorphism UI design
- 📱 Fully responsive layout
- ⚡ Lightning fast Vite build tool
- ☔ Dynamic weather emojis based on WMO weather codes
- 🏗️ Clean Architecture (Separation of concerns: API, UI, Main logic)

## 🛠️ Tech Stack
- **HTML5**
- **JavaScript (ES6+)**
- **Tailwind CSS v3**
- **Vite**

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/weather-app.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

## 📂 Project Structure
```text
src/
├── api.js     # Handles all API requests to Open-Meteo
└── ui.js      # Handles DOM manipulation and dynamic UI updates
main.js        # The orchestrator (Event Listeners & Logic)
index.html     # Application skeleton and styling classes
```
